## 歷年指導紀錄欄位格式

「新北市在職清冊」工作表中的「歷年指導紀錄」欄位使用 JSON 儲存兩種紀錄。沒有資料時，兩個陣列都使用空陣列：

```json
{
  "assistantRecords": [
    { "year": 113 }
  ],
  "traineeRecords": [
    {
      "year": 113,
      "studentName": "學員姓名",
      "city": "所在縣市",
      "district": "行政區域",
      "unit": "服務單位名稱",
      "shots": 10
    }
  ]
}
```

管理者可在工作人員資料明細中的「歷年指導紀錄」按「直接修改」，透過表單新增或刪除初訓年度及學員指導紀錄，填妥各欄位後儲存。系統會將表單資料轉為 JSON 儲存至清冊欄位。
